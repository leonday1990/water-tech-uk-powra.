WATER TECH UK POWRA - PWA TEST PACKAGE
Included: index.html (app with PWA hooks), manifest.webmanifest, service-worker.js, icons.

HOSTING FOR PILOT:
1. Create a GitHub repository.
2. Upload the contents of this folder to its root.
3. Settings > Pages: deploy from branch main, root folder.
4. Open the HTTPS Pages link on mobile.
5. iPhone: Safari > Share > Add to Home Screen. Android: Chrome menu > Install app/Add to Home screen.

LIMITATIONS/SAFETY:
This is a pilot package. Assessments are NOT centrally saved; they remain in the worker's browser unless exported/copied/printed.
Service worker caches the local app shell only. Tailwind is externally loaded, so offline appearance/function needs testing and may be incomplete.
GitHub Pages is public to visitors even if repository is private; do not use with sensitive work data. Use HTTPS.
Do not treat this as an approved company H&S records system until access controls, retention, backups, and operational tests are completed.
